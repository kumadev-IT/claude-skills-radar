Skills Radar

Views

  • Score: the main ranking. It balances how popular a repo is, how fast it is growing right now and how actively it is maintained. Use it to see what matters at the moment.
  • Hot: sorted only by stars gained per day. Shows what is taking off right now, even if it is small or brand new.
  • New: youngest repos first. Use it to discover just-published projects that have already passed the minimum star threshold.
  • All-time: the most-starred repos ever, including stale or archived ones. The number on the right is total stars, not the Score. Badges: stale Xmo if there has been no push for more than days, archived if the author has closed it, active if it is maintained and Score #n if it also appears in the Score ranking.

Reading a row

  • Number on the left: position in the ranking. Below it: ▲n / ▼n positions gained or lost since the previous update, new if it has just entered the ranking.
  • ★ total stars · +N/day stars per day. A ~ means the value is estimated (stars ÷ repo age) because there is no history yet; after about a day of updates it is measured over the last days. Highlighted in orange at ≥ 20/day.
  • pushed: last commit · age: age of the repo.
  • Number on the right: the Score (0–100). The bar shows what it is made of: momentum popularity freshness. Hover over the score for exact values.
  • Sparkline: star count over time (appears once history is available).

How the Score is calculated

Popularity and momentum use a logarithmic scale and are relative to the best repo in the pool: the most-starred repo scores 1 on popularity, the fastest-growing one scores 1 on momentum. The logarithm keeps giants from crushing everyone else: going from 10 to 100 stars counts as much as going from 1,000 to 10,000. The Score is therefore a comparison between tracked repos, not an absolute grade.

Which repos are included

GitHub repos with the topics , at least stars and a push in the last days, excluding forks and archived repos. A separate search collects repos created in the last days, so newcomers are not buried by the big ones. Out of candidates, the top by Score are shown here.

All-time vs Score: which to use

All-time measures accumulated trust: stars add up over the years and almost never go down, so whoever is at the top stays there for a long time, even after development stops. It works like VS Code extension installs or the number of Amazon reviews: a strong reliability signal, but one that rewards whoever got there first.

Skills carry an extra risk: Claude Code and the skill format change quickly, and a skill untouched for months may be outdated or no longer work. Use All-time to find established references, always checking the activity badge, and Score/Hot to discover what is emerging. The sweet spot is a repo high in All-time with a Score #n badge: widely trusted and still alive.
